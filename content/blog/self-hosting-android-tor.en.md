Publishing web content without relying on third-party providers, Big Tech, or proprietary cloud infrastructure is the first step toward true digital autonomy.

In this article, we look at how to turn an old Android device into a low-power static web server accessible anywhere via the Tor network using **KSWEB** and **Orbot**.

---

### Why this approach?

* **Zero infrastructure costs**: No domain to buy, no monthly VPS.
* **Ecological footprint and minimal power consumption**: Android hardware minimizes electrical draw compared to a desktop server.
* **Structural privacy**: No public IP address exposed; the site resides entirely behind the encryption of Tor's Hidden Services.

---

### 1. Environment Setup: KSWEB

To serve the static pages generated by Hugo, we use **KSWEB**, a lightweight suite that includes an Android-optimized Lighttpd/Nginx server.

1. Install KSWEB on the device.
2. Configure the server's root directory to point to local storage, for example:
   `/sdcard/htdocs/`
3. Set the HTTP listening port to `8080`.
4. Start the web server in the background.

At this point, the pages inside `/sdcard/htdocs/` will be visible on the local network by entering the phone's IP (e.g., `http://192.168.1.X:8080`).

---

### 2. Exposing to the Tor Network: Orbot

To make the web folder accessible externally without router port forwarding or public IPs, we channel traffic through **Orbot**.

1. Open **Orbot** and navigate to the **Onion Services** section.
2. Create a new hidden service with the following parameters:
   * **Name**: `blog` (or an identifier of your choice)
   * **External Port**: `80`
   * **Internal Port**: `8080` (the port configured in KSWEB)
3. Save the configuration and start Tor.

Orbot will automatically generate a unique address with the `.onion` extension (e.g., `http://xyz...xyz.onion`).
